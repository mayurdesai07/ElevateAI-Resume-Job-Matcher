## 🌟 Overview

**ElevateAI** is a high-performance career intelligence platform and resume job matcher built with Next.js 14 and Tailwind CSS. It bridges the gap between candidates and high-paying roles through real-time ATS matching, 1-Skill Unlock diagnostics, and **Zara**, an autonomous Voice Career Strategist.

---

## ✨ Key Features

1. **Light / Dark Mode Theme Engine:**
   - High-contrast visual tokens (`#2563EB` primary, `#183B56` navy headings, `#44C654` vibrant success green).
   - 1-Click Sun ☀️ / Moon 🌙 Theme Engine with instant `localStorage` persistence and anti-flash rendering.

2. **Automated Resume Parsing & Permanent Memory:**
   - Upload any resume (PDF, TXT, or paste raw text) to instantly extract technical competencies, software tools, and key strengths.
   - Built-in user authentication and instant Guest login remember candidate profile data permanently across visits.

3. **Hyper-Local & Global Job Discovery:**
   - Real-time job filtering across Indian tech hubs (Bengaluru, Mangalore, Mysore) and international markets (San Francisco, New York, Singapore, Remote).
   - Live multi-feed sync pulling verified openings from LinkedIn Live, Greenhouse, and Jobicy with hourly auto-refresh.

4. **High-ROI 1-Skill Unlocks:**
   - Identifies the exact single skill gap (e.g., Snowflake, dbt, Airflow) holding candidates back from +35% to +50% higher compensation.
   - Generates tailored 30-day bridge schedules and portfolio project briefs to prove competency to hiring committees.

5. **Zara — Autonomous Voice Career Strategist & Talent Architect:**
   - 1-Click voice-to-voice and interactive chat coach powered by Web Speech API.
   - Simulates hypothetical career questions (*"What if I have Snowflake—would I get this job?"*, *"What skills do I lack for getting a new job?"*, *"Give me the jobs which are only one skill away from me"*).
   - Tailored salary negotiation scripts, interview question drills, and Google XYZ resume bullet rewrites.

6. **Application Pipeline Tracker & Greenhouse Sync:**
   - 1-Click enrollment to track application status (`Enrolled & Applied`, `Under Review`, `Interview Scheduled`, `Offer Received`).
   - Track recruiter response logs, email feedback, and next steps with direct Composio & Greenhouse ATS integration.

7. **Edge Security WAF & Anti-Tamper Architecture:**
   - Automated Edge firewall protecting against bot scanning, prompt injections, and script hijacking.
   - Strict Content Security Policy (CSP), HSTS, and X-Frame-Options headers.

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mayurdesai07/ElevateAI-Resume-Job-Matcher.git
   cd ElevateAI-Resume-Job-Matcher
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
